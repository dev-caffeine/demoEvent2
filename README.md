# Event Management Website (Demo)

A bilingual (**Marathi / English**) website concept for an event management company, built as a demo for a client pitch.

## Features
- Language switcher with full Marathi and English content
- Service sections: weddings, corporate events, birthdays and cultural shows
- Filterable event gallery
- Enquiry form for event bookings
- Responsive layout with animated transitions

## Built with
Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Lucide icons

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

> Gallery images are placeholders from Unsplash.
